# OWASP ASVS Level 1 checklist

This walks the OWASP Application Security Verification Standard 4.0.3, **Level 1**, requirement by requirement, against this repository as it stands. `SECURITY.md` is the short version; this is the evidence behind it. Chapter V1 (architecture) has no Level 1 requirements and is omitted for that reason. We reviewed against Level 1 only: we make no claim about Level 2.

Four statuses: **Implemented** (the control exists and is exercised), **Partial** (it exists with the caveat stated), **Not applicable** (the requirement assumes a feature this system does not have, by design), and **Limitation** (it applies and the control is missing today). Each row names the file or test a reader can open. Where a row says "checked by search", the claim is that a search of the named directories found nothing; it is not a proof of absence.

Requirement text is quoted from ASVS 4.0.3, © OWASP Foundation, licensed CC BY-SA 4.0.

**What this does not cover.** It does not test TLS, headers or cookies against the live deployment: rows that depend on Render's edge say so. It was written by reading our own code and configuration, so it can be wrong where we misread it. A penetration test would be the next step, and none has been done. The red-team sessions in `docs/red_team.md` are a different thing: they probe the assistant, not this checklist.
