From 10% to 100% of the training data the mean dev macro-F1 goes from 0.5133 to 0.9003. The last step, from 75% to 100%, adds +0.0553, more than the whole spread of the 75% subsamples (0.8082 to 0.8703): the curve is still rising at the end, which says more data of this kind would probably help. Two cautions: the full-data point is one run, and it is the configuration chosen on this dev set.

## What this does not show

- Every number here is on the dev half of a held-out set written by the same team that wrote the training text, so shared phrasing habits can flatter all of it (`EVALUATION.md`).
- 88 dev utterances is small: an interval that contains 0 means "we cannot tell", not "they are equal".
- The grid varies two choices. It does not search n-gram ranges, class weights or other model families, and it does not tune the escalation threshold, which was chosen separately on dev.
