# ML experiment tracking: a snapshot of the MLflow runs

The MLflow store is local and git-ignored, so this page is the part of it a reader of the repository can see. Snapshot of 4 top-level runs (1 classifier selection, 3 system evaluations), made with code at `dc65c26` (uncommitted changes: `false`), from the first run at 2026-10-01T05:05:02+00:00 to the last at 2026-10-01T05:07:42+00:00 (UTC).

Generated by `python -m eval.tracking_report`. Reproduce the runs with `make train-eval`, `make eval` and `make eval-adversarial`, then `make mlflow-ui` to browse them or `make tracking-report` to regenerate this page.

**What is not in it:** the live-model runs (`make eval-live`), because they need API keys and billing that were not used to make this snapshot. Their results are in `eval/reports/SYSTEM_EVAL_LIVE.md` but were not tracked here.

## Limits

- A snapshot, not a live view: it is as old as its generation date. The store itself stays local.
- Tracking records what ran and what it measured; it does not make a result better or more independent. The data behind these runs is the team-written sets described in `EVALUATION.md`.
- The comparison with the reports checks the headline numbers only, not every metric each run logged.
